# Testing Workflow

To test the application efficiently, follow these steps:

1. **Run Automated Tests**:
   - Run `pnpm test` to re-run the tests.
2. **Manual Tests**
   - Run `pnpm start` and view the site at the URL supplied by the web server
   - Assessment page: `http://localhost:8080/deployment.html`
   - Results page: `http://localhost:8080/deployment.html?deployers_1=1&throughput_1=3&throughput_2=3&software_automation_1=3&software_automation_2=1&view=results`
