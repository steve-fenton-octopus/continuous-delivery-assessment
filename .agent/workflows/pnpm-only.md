# Use pnpm

This project uses `pnpm` as its package manager. Do not use `npm` or `yarn`.

- **Installation**: Use `pnpm install`
- **Adding dependencies**: Use `pnpm add <pkg>` or `pnpm add -D <pkg>`
- **Running scripts**: Use `pnpm start` or `pnpm run <script>`
- **Updating**: Use `pnpm update`
